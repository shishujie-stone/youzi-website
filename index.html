Mac 提示无法验证开发者，怎么办？

目前是未公证的体验版本。先确认文件来自本页面，再按 macOS 的对应提示处理；如系统允许，可在「系统设置 → 隐私与安全性」查看本次打开的提示。如果提示文件损坏或无法继续，请停止安装并等待公证版本，不需要关闭系统安全保护。

柚子真的免费吗？

桌宠免费下载和使用。可选 AI 聊天需要你自己的 DeepSeek API key，其接口费用由 DeepSeek 收取；不设置也能使用桌宠动作。

会读取我的聊天消息吗？

微信提醒只检测微信 Dock 图标的未读标记，不读取消息内容，未读标记不变化时可能漏报。你主动发送的 AI 对话直接提交给 DeepSeek；聊天记录只保留在本次运行的内存中，密钥优先保存在系统钥匙串中。

怎样退出和卸载？

右键点击柚子，选择「退出」。如配置了 API key，可先在聊天设置中移除密钥，再退出并从「应用程序」删除柚子。
